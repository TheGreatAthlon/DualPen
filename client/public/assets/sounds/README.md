# Presence & notification sounds

| Filename | Trigger | Loop? | Character |
|---|---|---|---|
| `collab_same_line_idle_tick_loop.wav` | peer idle on your line | seamless loop | quiet, slow analog clock tick — unobtrusive over long stretches |
| `collab_same_line_typing_loop.wav` | peer typing on your line | seamless loop | fast mechanical clicking, clearly faster/busier than the idle tick |
| `collab_elsewhere_typing_click.wav` | peer typing elsewhere | one-shot, rate-limited retrigger | soft, muted, "further away" than the same-line loop — peripheral, not attention-grabbing |
| `chat_message_notify.wav` | new chat message | one-shot | short, pleasant, tonally distinct from the click/tick sounds so it's never confused with presence |
| `collab_peer_joined_doc.wav` | another user opens the document you have open | one-shot | short rising two-note chime |
| `collab_peer_left_doc.wav` | another user closes/leaves the document you have open | one-shot | short falling two-note chime — mirror image of the "joined" sound so join/leave are distinguishable by ear |

These six files are currently **synthesized placeholders** (simple tones, generated by
`client/scripts/gen-placeholder-sounds.py`) standing in for real sound design, so the
playback pipeline (loading, decoding, looping, mixing, mute/volume) can be built and
tested end-to-end now. Replace them with real audio later — keep the exact filenames
above so no code changes are needed, and keep the loop points seamless for the two
loop assets.
